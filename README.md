# reference

情報共有のための公開リポジトリです。

| フォルダ | 概要 |
| --- | --- |
| [backoffice](backoffice/) | バックオフィス専門のAIエージェント向けの[AGENTS.md](backoffice/AGENTS.md)。会社のバックオフィスと個人の資産・税務管理、情報整備、タスクと期限の管理などの方針。 |
| [devoffice](devoffice/) | AIエンジニア向けの[AGENTS.md](devoffice/AGENTS.md)と[スーパーコンペモードのスキル](devoffice/.agents/skills/super-competition/SKILL.md)。プロダクト開発、設計・実装の判断、品質管理などの方針。 |

各フォルダには、同名リポジトリの作業方針を収録しています。`devoffice`にはスキルも収録しています。`abby`は`backoffice`へ、`koala`は`devoffice`へ移管され、旧リポジトリは削除済みです。`backoffice`の役割は、汎用秘書から上記のバックオフィス業務に特化しています。

このリポジトリ自体の運営ルールは、ルートの[AGENTS.md](AGENTS.md)に記載しています。
