# reference

情報共有のための公開リポジトリです。

| フォルダ | 概要 |
| --- | --- |
| [backoffice](backoffice/) | バックオフィス専門のAIエージェント向けの[AGENTS.md](backoffice/AGENTS.md)。会社のバックオフィスと個人の資産・税務管理、情報整備、タスクと期限の管理などの方針。 |
| [devoffice](devoffice/) | AIエンジニア向けの[AGENTS.md](devoffice/AGENTS.md)、[スーパーコンペモードのスキル](devoffice/.agents/skills/super-competition/SKILL.md)、利用者視点で使い勝手や価値の伝わり方を確かめる[ペルソナフィードバックのスキル](devoffice/.agents/skills/persona-feedback/SKILL.md)。プロダクト開発、設計・実装の判断、品質管理などの方針。 |

各フォルダには、同名リポジトリの作業方針を収録しています。`devoffice`にはスキルも収録しています。`abby`は`backoffice`へ、`koala`は`devoffice`へ移管され、旧リポジトリは削除済みです。`backoffice`の役割は、汎用秘書から上記のバックオフィス業務に特化しています。

このリポジトリ自体の運営ルールは、ルートの[AGENTS.md](AGENTS.md)に記載しています。

各スキルの背景は、スーパーコンペの[設計理由と検証の限界](devoffice/.agents/skills/super-competition/references/design-rationale.md)と、ペルソナフィードバックの[設計理由と検証記録](devoffice/.agents/skills/persona-feedback/references/design-rationale.md)を参照してください。これらの文書内の原資料のコミットとパスは、同期元の`devoffice`リポジトリの履歴・作業環境を指します。
